# 🌐 Cloud Platforms — Team Portfolio
**Woosong University · Computer Science · 2026**

A multi-page personal portfolio website built as a group project for the Cloud Platforms course. Each team member has their own portfolio page showcasing their skills, projects, and background. The site is deployed as a static web app using **Microsoft Azure**.

## 🎯 Project Objectives

- Build individual self-portfolio pages using **HTML, CSS, and JavaScript**
- Create a shared **main dashboard** to navigate between team member portfolios
- Version control the project using **GitHub**
- Deploy and host the site using **Azure Static Web Apps**
